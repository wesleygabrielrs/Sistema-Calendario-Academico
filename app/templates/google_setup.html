Para o app conseguir mandar seus eventos para o Google, você precisa criar um credentials.json (uma única vez, ~10 minutos, gratuito).

1

Abra console.cloud.google.com e entre com a sua conta do Google.

2

No topo da página, clique em Selecionar um projeto → Novo projeto → dê um nome (ex.: calendario-academico) → Criar.

3

Menu ☰ → APIs e serviços → Biblioteca → pesquise Google Calendar API → clique → Ativar.

4

APIs e serviços → Tela de consentimento OAuth → escolha Externo → preencha o nome do app (ex.: Calendario UNINASSAU) e seu e-mail → salve. Nos passos de escopos e usuários de teste pode avançar direto.

5

APIs e serviços → Credenciais → + Criar credenciais → ID do cliente OAuth → tipo Aplicativo para desktop → Criar → no aviso que aparece, clique em Baixar JSON.

6

Renomeie o arquivo baixado para credentials.json e coloque na pasta Calendario-Academico (junto do app.py). Depois clique abaixo.

Já salvei — conectar agora

🔒 O credentials.json e o token gerado (token.google.json) são seus — os dois estão no .gitignore e não vão para o GitHub.
